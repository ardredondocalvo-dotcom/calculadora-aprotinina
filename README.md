# Calculadoras UCI PWA

Paquete web estático para APACHE II, SOFA, Glasgow, Murray, PaO2/FiO2 y codificación EQ-5D-3L.

## Publicación
Suba todos los archivos de esta carpeta a un alojamiento HTTPS (SharePoint static hosting no siempre admite service workers; GitHub Pages, Azure Static Web Apps o un servidor web HTTPS sí). Abra index.html.

## Privacidad
No usa cookies, localStorage, cuentas, base de datos ni red. Los campos se pierden al recargar/cerrar. El service worker solo almacena los archivos de la aplicación para uso sin conexión.

## Validación
Antes de uso en investigación o asistencia, valide cada resultado contra casos de prueba aprobados por el promotor. EQ-5D requiere autorización de EuroQol y debe usarse con la redacción oficial licenciada.
